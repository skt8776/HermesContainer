# PM Approval Gate Policy

Policy
- PM may plan proactively on a schedule.
- PM must not start execution automatically.
- Every proposed task must be presented to the user in Discord with an explicit approval request.
- Only after user approval should implementation/delegation work begin.

Allowed without approval
- Project inspection
- PRD refinement
- Prioritization
- Task proposal
- Acceptance criteria drafting

Blocked until approval
- Implementation
- Code changes
- Delegation to builders/reviewer/qa for execution work
- Any action framed as "starting work"

Expected PM message shape
- Highest-priority task
- Why it matters now
- Recommended teammate(s)
- Completion criteria
- Explicit approval request

Example approval line
- "이 작업을 진행해도 될까요? 승인해주시면 다음 단계부터 실행을 시작하겠습니다."
